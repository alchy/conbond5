# conbond5 v1 — implementační plán

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Konverzační systém s grafovou pamětí, který každou českou větu
zapíše jako výrok s epistemickým stupněm a nad pamětí hodnotí výroky
(ANO/NE/NEVÍM s důkazem a zdrojem), měřený na korpusu conBond2.

**Architecture:** Rozbor z UDPipe (`oracle`) → tabulkové čtení, kde
každý token skončí v roli/atributu/vnoření/částici/zbytku (`read`,
`chronos`) → grafová paměť výroků a uzlů s proveniencí a stupněm
(`memory`) → shoda dotazu s výroky přes uzávěry (`logic`) + propad
aktivací (`recall`) → dialog a žurnál (`dialog`) → české šablony
(`render`) → měření (`bench`). Spec:
`docs/superpowers/specs/2026-08-16-conbond5-design.md`.

**Tech Stack:** Python 3.11, `networkx`; dev `pytest`, `mypy`. UDPipe
služba `cb-udpipe` na `127.0.0.1:42200` (conBond3), model
`cs_all-ud-2.17-251125`; testy hermetické přes nahrané rozbory (JSON).

## Global Constraints

- Python `>=3.11`; jediná běhová závislost `networkx>=3.0`.
- Docstringy česky, bohaté: proč / co / vstup / výstup (preference J.).
- Persistence pouze JSON, deterministické id (`s0001`, `e0001`, `g0001`,
  `p0001`, `t0001`, `o0001`), žádné hodiny ani neseedovaná náhoda; „teď“
  = číslo tahu.
- Nikde brána zápisu: přečtená věta se zapíše vždy; nepřečtené = zbytek
  + otevřená položka.
- Pravdivost nikdy neteče po měkké hraně; aktivace jen řadí.
- Testy nesahají na síť: rozbory jsou nahrané v `tests/data/parses.json`
  (klíč = text věty), pořizuje je `python -m cb5.record` proti službě.
- Každý test čtení hlídá „nic se neztrácí“: každý token má právě jedno
  místo určení.
